# CodeAlpha_AI_Chatbot

## Objective

Develop a Java-based AI Chatbot capable of interactive communication with users through a graphical user interface. The chatbot should process user input, provide automated responses, and answer frequently asked questions.

## Requirements Implemented

### 1. Create a Java-based Chatbot Application

A desktop chatbot application was developed using Java and Java Swing.

### 2. Use Natural Language Processing (NLP) Techniques

The chatbot uses basic NLP techniques including:

* Text normalization using `toLowerCase()`
* Keyword matching
* Intent recognition
* User input processing

### 3. Implement Rule-Based Answers

The chatbot generates responses using predefined rules and conditions based on user queries.

### 4. Train the Bot for Frequently Asked Questions (FAQs)

A FAQ knowledge base is implemented using `HashMap` to store common questions and answers. The chatbot automatically responds when a matching FAQ is detected.

### 5. Integrate with GUI for Real-Time Interaction

A professional Java Swing GUI is provided for real-time communication between the user and chatbot.

## Additional Features

* Interactive chat interface
* FAQ system
* Date and time responses
* Random greeting responses
* Chat history storage
* User-friendly interface
* Real-time message processing

## Technologies Used

* Java
* Java Swing
* OOP Concepts
* Collections Framework (HashMap)
* File Handling
